## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/TokenOutline.git`
2. `cd TokenOutline`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TokenOutline, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
